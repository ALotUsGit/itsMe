# 안녕하세요! 전아련입니다.
퍼블리셔로 4년간 일하던 중 프론트엔드 직무에 흥미를 느껴 직무를 변경하게 되었습니다.

- 운영 시스템 중심 관리자 UI 설계 및 구현
- 프론트엔드 단독 담당 환경에서 서비스 UI 아키텍처 설계
- 레거시 환경(jQuery/Mustache)에서 신규 기능 개발 및 기존 기능 개선
- 운영/CS팀과 협업하여 관리자 UX 개선
- React 기반 CMS 전환 프로젝트 진행

[포트폴리오 바로가기](https://alotus.vercel.app/)

### 주요 기능
- 프로젝트별 기간, 참여인원, 주요역할 등 소개
- 프로젝트 별 링크 공유 및 새로고침을 고려한 병렬 라우팅 및 인터셉트 라우팅 구현
